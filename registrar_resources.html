Playbook 1 • Data Hygiene & State Reporting

CALPADS Audits & Residency Verification

CALPADS updates require clean student profile records to guarantee the district matches correct State Student Identifiers (SSIDs). Any demographic errors, missing parent contact flags, or unverified boundaries can block active district funding claims.

Demographic Cleaning & SSID Mapping Sequence:

  1. Perform a global duplicate check: Before requesting an SSID or adding a demographic, search the entire district.
    Aeries: Student Data → Search All Students

    If the student attended WUSD years prior, do not build a brand-new profile. Request an administrative record transfer to prevent duplicate SSID registrations.

  2. Verify Legal Names and Parent Details: CALPADS requires student legal names to match state-issued birth certificates exactly. Confirm that at least one primary parent or guardian is checked as the primary contact with an active email address.
  3. Verify Out-of-District Boundary Clearances: If a student resides outside of district bounds but is enrolling, do not save an active demographics profile until the physical Inter-District Transfer Permit has been collected, signed, and saved to specialized files.
    Aeries Path: Student Data → Specialized Programs → Enter Inter-District Status
🚨 State Auditor Warning:

Any student with active CALPADS reporting errors (e.g., mismatch in birth country coding, missing primary home language tags, or open program end dates) is automatically excluded from active district unduplicated pupil counts (UPC), directly lowering localized state funding allocations.

Playbook 2 • Special Program Configurations

Foster Youth & McKinney-Vento Program Coding

Students meeting McKinney-Vento (Homeless Assistance Act) or Foster Youth criteria are protected under federal law, granting them immediate school registration privileges and enrollment safety checks.

How to Code Special Program Status:

  1. Locate and open the Special Programs (SSD) module: Look up the student ID in Aeries.
    Left Menu: Student Data → Programs → Special Programs
  2. Add a new Program Record: Click the **Add** button. Set the program code to your district's specific Homeless/Insecurity code (e.g., **5** or **McKinney-Vento**).
  3. Enter exact dates: Set the **Start Date** to the exact day the housing affidavit was verified or the foster placement occurred. Never leave the Start Date blank.
  4. Update Primary Residence Code: Navigate to Demographics (STU) and ensure the corresponding **Resident Status** dropdown matches the verified living arrangement (e.g., Doubled-up, Shelter, Unsheltered).

Playbook 3 • Schedule Engineering & HIS Records

Processing Schedule Changes & Audit Gaps

Preventing Period Gaps during Drop/Add Changes

Secondary registrars frequently process schedule changes initiated by counselors. Dropping and adding sections out of sequence can create blank period gaps on student profiles, raising severe attendance tracking errors.

  1. Open the student's **Classes / Course Schedule** page in Aeries.
  2. Before hitting Update, check the class maximum caps on the incoming section. If the class is full, consult scheduling leads before executing an override.
  3. When updating, assign matching **Effective Start & End Dates** on both the dropped section and the added section. Dropping a section yesterday but adding the replacement tomorrow generates an unauthorized 1-day scheduling gap.
Aeries Path: Student Data → Classes → Click [Change] → Update sections

Transcripts, Records Requests, and Cumulative Transfers

When a student registers or exits, coordinating cumulative records (Cum Files) and Course History (`HIS` table) must remain a high priority to ensure academic continuity.

  1. Execute Official Transcript Audits (HIS): For incoming high school students, translate their out-of-district transcript credits into standard WUSD equivalents and save them directly in Course History.
  2. Release outgoing records: Upon receiving a validated records request from an outside district, pull the student's physical folder, photocopy the documents, print the final transcript, and log the release in cumulative records.
  3. Day-1 No-Show Cleanup: Run Rosters checks on opening day. If an enrolled student fails to attend by your district's designated window, withdraw them using the day *before* the start of school as their exit date, assigning the appropriate **N - No-Show** exit code to clear seat counts.
