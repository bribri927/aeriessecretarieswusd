Creating & Duplicating Assignments

When adding assignments, make sure you configure your settings correctly. For teachers with multiple class sections, Aeries features a native duplicating tool that prevents hours of repetitive data entry.

Open Gradebook → Click 'Add Assignment' (or hover on existing, select 'Copy Assignment')

The Standard Field Setup Flow:

  1. Assign & Due Dates: Keep dates accurate. Aeries uses the due date to determine which quarter or trimester the student gets credit for.
  2. Formative vs. Summative: Tag sections cleanly. Setting up assignment descriptions correctly makes parent progress reports easy to read.
  3. Safe Duplication: In your assignment configuration panel, check the boxes next to your adjacent linked class periods. Aeries will instantly push the new assignment structure across all checked periods automatically.

Mass Entry & Rapid Grading

You don't need to open individual student cards to key in grades. Using the **Mass Entry** dashboard lets you apply baseline scores and then quickly make exceptions for late or missing assignments.

Open Gradebook Card → Select Assignment Column → Click 'Mass Entry' Button

Mass Input Steps:

  1. Open the Mass Entry card. You will see your full roster vertically listed with empty fields.
  2. Use **"Apply Default Score"** to assign a baseline grade (e.g., 10/10) to the entire class in a single click.
  3. Go down the list and manually adjust scores for students who did not turn in the work, or use custom override codes.
  4. Click **Save Scores**. All entries will write directly to your database files.

Gradebook Math • Extra Credit Protocols

Compliant Extra Credit & Point Bounds

Aeries offers two main ways to handle extra credit. Doing it incorrectly can accidentally skew a student's final average.

Method A: Over-Max Points Entry

Enter extra credit directly onto an existing assignment:

  • Keep maximum points set to its true value (e.g., 50).
  • Input student scores above maximum (e.g., 52/50).
  • Aeries calculates this as $104\%$ for that specific assignment, raising their total class score.
Method B: Zero Max Points Assignment

Create a dedicated extra credit assignment card:

  • Set **Max Points** to `0`.
  • Enter student points earned (e.g., 5).
  • Aeries treats this as a points bonus without adding to the gradebook's total available points.
⚠️ The Weighted Extra Credit Trap:

If your gradebook uses **Weighted Categories** (e.g., Tests 60%, Homework 40%), creating a separate assignment with 0 Max Points will only impact the category it is placed in. If you put it in a category with no other graded assignments, Aeries cannot calculate the math, which can cause student grades to display incorrectly!

Pedagogical Methods • Curving Roster Scores

How to Apply Curves in Aeries

Aeries does not have an automatic grading curve button. However, teachers can easily apply standard curves using these manual workflows:

  • Method 1: Adjust the Grading Scale. Under **Manage Gradebook → Grading Scale**, you can lower letter thresholds (e.g., setting an A to start at 88% instead of 90%) to adjust grades without editing individual scores.
  • Method 2: Flat Point Curve. Add a set number of bonus points (e.g., +3 points) to every student’s score in your mass-entry grid.
  • Method 3: Multiplier Curve. Multiply student scores by a set factor (such as 1.05) to apply a proportional curve.
