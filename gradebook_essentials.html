Milestone 1 • Term Transition

Copying Gradebooks (The August Time-Saver)

If you taught this course last year or need to duplicate configurations across semester terms, never build your categories and weights from scratch. Use the Aeries **Copy Gradebook** wizard to mirror structures in seconds.

Left Sidebar → Gradebook → Click 'Add Gradebook' → Select 'Copy Gradebooks' Tab

Standard Copier Workflow:

  1. Open the Copier utility. The source menu will list your active historical databases.
  2. Select the target source gradebook you want to duplicate (e.g., *English 9 - Fall 2025*).
  3. Check the option boxes for the structures you wish to copy: **Categories**, **Grading Scale**, and **Gradebook Options**. Do not check 'Assignments' unless you plan to reuse exact dates.
  4. Select the destination active gradebook you are establishing for this term.
  5. Click **Copy Selected Gradebook**. Aeries will import the parameters and build your framework instantly.
⚠️ Common Copy Warning:

Copying gradebooks only duplicates structure framework parameters. It **does not** enroll students. Students must always be linked via standard course section rosters!

Milestone 2 • Cohort Consolidation

Linking Course Sections

If you teach three separate periods of the same class (e.g., Period 1, 3, and 5 Biology), you do not need to create three different gradebooks in Aeries. Linking them lets you manage assignments and entries in a single, combined interface.

Open Gradebook → Click 'Manage Gradebook' → Select 'Add/Link Sections' Tab

How to Link Sections:

  1. Select your primary gradebook card representing Period 1.
  2. Open the Link Sections tab. You will see a list of adjacent course sections taught by you.
  3. Check the boxes next to matching sections (e.g., Periods 3 and 5) to pair them.
  4. Click **Save**. Your gradebook is now linked. When adding an assignment, it will render across all three periods automatically.
💡 Why this is awesome:

Linking sections saves you hours of duplicate data entry. You only create the assignment once, enter grades across a unified list, and push updates in a single click, while keeping period rosters completely separate for attendance checks.

Milestone 3 • Category Structure

Setting up Categories & Weighted Grades

How final grades are calculated is determined by your gradebook options. Setting up categories first prevents grading calculation anomalies during active semesters.

Open Gradebook → Click 'Manage Gradebook' → Select 'Categories' Tab
Method A: Point-Based Grading

Calculates grades using simple division:

$\text{Final Grade} = \frac{\sum \text{Points Earned}}{\sum \text{Max Points}}$

Every point has equal weight. Useful for elementary layouts where assignments share similar point structures.

Method B: Weighted Grading

Syllabus weights allocate percentage shares:

$\text{Final Grade} = \sum (\text{Category \%} \times \text{Category Weight})$

Check the box labeled **Do Weighted Grading** under Gradebook Options and input category proportions (e.g., Homework 20%, Assessments 80%).

Milestone 4 • Gradebook Policies

Score Tags, Late Work, & Exclusions

Aeries contains specific tag codes designed to track student compliance and work submissions without manually overriding point values.

MI (Missing)

Counts mathematically as a **0% score** in final calculations while triggering alerts on student and parent dashboards. Excellent for tracking late work.

EX (Excused)

Bypasses calculation completely. This assignment does not hurt or help the student's cumulative average.

Drop Lowest Score

Under **Manage Gradebook → Categories**, you can configure Aeries to automatically drop a student's lowest quiz or homework score within that category.

Milestone 5 • Reporting Timeline

Grading Windows & Comments

When the reporting period ends (Trimester or Quarter), gradebooks must be updated and rolled into standard Report Card tables (`GRD`).

Grading Window Protocol:

  1. Ensure all scores are entered, and unsubmitted assignments are marked with `MI` or a zero score.
  2. Navigate to **Grades → Grade Reporting → Initialize Grade Reporting**.
  3. Load teachers' electronic gradebook entries directly into report card tables.
  4. Double-click the comments field on report card screens to add standardized remarks (such as *Consistently turns in high-quality assignments* or *Needs regular homework review*).
  5. Print and submit signed **Grade Verification Sheets** to your site office.
