Step-by-Step • Diagnostic Audit

Auditing Parent Portal Login History

A common mistake is assuming parents see every assignment grade in real-time. Before blaming families for disengagement, check whether they have successfully created and verified their parent portals.

Left Sidebar → Student Data → Medical → Portal Accounts (or Parents/Contacts Tab)

How to Check Parent Login Status:

  1. Search for the student to load their master demographics profile.
  2. Select **Portal Accounts** or expand the contacts section to view linked emails.
  3. Audit the "Last Login Date" field: If it remains blank or says *Never*, the parent hasn't linked the child.
  4. Check Verification Codes: If unlinked, click **Print Portal Verification Letters** to generate their unique Student ID, telephone, and Verification Code (VPC). Email or print this code directly for the family.

Automated Workflow • Time-Saving Outreach

Sending Proactive Bulk Alerts for Missing Work

Rather than emailing twenty different parents individual progress messages, Aeries features a native mass outreach engine designed to pull outstanding `MI` (Missing) markers and send parent notifications in bulk.

Open Gradebook Card → Select Reports → Missing Assignments Listing → Email Notifications

The Mass-Email Notification Workflow:

  1. Open your gradebook. Click on **Reports** in the header.
  2. Select **Missing Assignments**. Under options, filter the minimum threshold (e.g., *at least 1 missing assignment*).
  3. Toggle the option **"Email Parents of Selected Students"**.
  4. Aeries dynamically builds an email linking exactly which assignments remain outstanding (e.g., *Trig Functions, Unit Exam 4*) and sends it securely to every registered parent.

Interventions paper Trail • Compliance

Logging Parent Contacts (Intervention Logs)

If a student is in danger of failing a grading term, California Education Code requires parent notification before issuing a failing mark. Documenting your parent conversations inside the **Contact Log** builds a secure compliance history.

Left Sidebar → Student Data → Demographics → select Contact Log tab

How to Create an Intervention Contact Log:

  1. Search student, select **Contact Log** under details.
  2. Click **Add New Record**. Populates current date/time automatically.
  3. Choose **Contact Code** (e.g., *Telephone*, *Email*, *In-Person Conference*).
  4. In the **Comments** area, note findings objectively:
    "Notified parent of outstanding Unit 4 exam. Scheduled makeup tutoring for Tuesday after school."
  5. Click **Save**. This entries is visible to counselors, administrators, and future teachers, ensuring unified student support.

Exporting Reports • Family Translations

Printing, Exporting, and Multi-Language translation

WUSD is home to a diverse student body. Aeries reports can be exported to PDF and are optimized to support auto-translations into families' registered home languages.

  • Roster translation settings: Under student demographics, Aeries displays the registered **Home Language (HL)**. When generating progress report letters, check the box *“Print in Home Language”* to translate standard terms automatically.
  • Clear progress report printing: Print standard summaries using the **Student Progress Report** format. Uncheck *“Include assignments not graded”* to keep the report simple for parents.
