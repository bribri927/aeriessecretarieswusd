Daily Operation • Parent Communications

Running Parent-Ready Progress Reports

Aeries provides a native printing engine designed to output cleanly formatted progress sheets for parents. Running these reports protects you during grading disputes by providing a clear paper trail.

Left Sidebar → Gradebook → Reports → Student Progress Report

Standard Report Printing Steps:

  1. Select Parameters: Check options to display category breakdowns, individual assignment scores, and teacher comments.
  2. Parent Signature Line: Toggle on the **"Include Signature Line"** property. This is highly recommended for students currently falling below a C average.
  3. Portal Exclusions: Ensure you do not print "unpublished" or draft grades that haven't been finalized in your Gradebook defaults.
2
Trimester / Quarter Rollover • Administration

End-of-Term Grade Rollover & Verifications

At the end of each reporting period, gradebooks must be cleanly closed, audited for exceptions, and submitted to the administrative registrar.

Left Sidebar → Grades → Grade Reporting → Initialize Grade Reporting

The End-of-Term Sequence:

  1. Zero Out Blank Work: Make sure no assignments remain as a blank field unless excused. Turn blanks into zero scores or use the `MI` (Missing) code.
  2. Load Grades from Gradebook: Execute the system import. This pulls final percentage marks directly into the report card table (`GRD`).
  3. Input Comments & Citizenship: Enter citizenship metrics (Outstanding, Satisfactory, Needs Improvement) and choose standardized comments (e.g., *Hardworking*, *Consistently participates*).
  4. Print Grade Verification Sheets: Print, review, sign, and deliver the final verification sheets to your site clerk to certify submission.
3
Early Intervention • Student Success

Missing Assignment Sweeps & Progress Monitoring

Waiting until the end of a grading window to find failing grades is too late. Running proactive missing assignment sweeps enables timely intervention.

  • Missing Assignments Listing: Run the "Missing Assignments" report weekly. This lists students who have accumulated more than a set threshold of `MI` tags (e.g., 3+ missing assignments) across your roster.
  • D/F Grade Monitoring: Under **Grades → Gradebook Summary**, you can filter your active view to only show students currently sitting below 70%. Use this list to coordinate tutoring and contact parents.
