Master Scheduling Query Workspace

Aeries database queries are the ultimate diagnostic tool to identify structural, teacher, and student data errors in your master schedule. Use this workspace to copy starter templates or chat with our Aeries Query AI Assistant to instantly generate custom syntax for your live audits.

Aeries Core Table & Field Quick-Reference

Master scheduling queries relies on targeted instructions sent to several database tables. Refer to this quick sheet before compiling your queries:

STU (Student)
  • ID: Student ID
  • NM: Name (Last, First)
  • GR: Grade Level
  • SG: Scheduling Group
SSS (Course Requests)
  • CN: Course Number
  • C2: Alternate Course
  • AL: Exclude Course Flag
  • PR: Priority Level
MST (Master Schedule)
  • SE: Section Number
  • CN: Course Number
  • MX: Maximum Seats
  • ACT: Active Enrollment
SMS (Scheduling Master)
  • SE: Section Number
  • RM: Room Code
  • PD: Period Number
  • CSQ: Class Calendar Link
