Unlocking Aeries Flex Scheduling Models

Aeries Flex Scheduling is a powerful paradigm shift in student-centered schedule building. Moving away from traditional 10-period limits, Flex Scheduling enables schools to support unlimited periods, overlapping start times, multiple instructors per section, and customizable calendars. Open this workspace page on one side of your monitor and your active Aeries database on the other to plan and build your flex structures systematically.

The "Why" and "How" of Flex Models

Traditional secondary schedules are locked into rigid structural periods. Pedagogical models like WIN (What I Need) blocks, advisory hours, and rotating block sessions require dynamic time segments. Working within Aeries Flex Scheduling removes these constraints by introducing the FTF (Flex Periods) and CCL (Class Calendars) tables.

Our Training Goal:

Together, we are going to understand how Flex Scheduling works, configure custom Flex Periods, associate Class Calendars, and leverage non-conflict code options to construct seamless, multi-teacher block schedules.

The Live Checklist We Are Building

  • Phase 1: Convert traditional SMS table setups to Flex structures.
  • Phase 2: Define distinct Flex Periods with custom start/end times.
  • Phase 3: Build unique Class Calendars for specialized rotations.
  • Phase 4: Map multiple instructors using Staff-Section Associations.

Understanding the Aeries Tables We are Modifying

As you build a Flex schedule, you are actively writing configurations across several key database tables. Let's make sure you know where this information lives:

FTF (Flex Periods Setup)

Houses your school's customized period identifiers (Short Titles), start and end times, and period types.

CCL / CCD (Class Calendars)

Tracks exact calendar dates when a specific flex period or section is active. Great for alternating A/B days.

STF (Staff Association Table)

Replaces traditional TCH records. Enables you to assign multiple staff members to a single section with custom role titles.

SMS / MST (Scheduling Sections)

Connects course IDs to a Flex Period sequence (SMS.FSQ), Class Calendar index (SMS.CSQ), and exclusion flag properties (SMS.ES).

The 5 Flex Training Milestones

Perform these configurations systematically in your Aeries staging database environment alongside this training guide.

Step 1 — Initialize Flex Scheduling on Scheduling Setup

Flex Milestone 1 • Initialization

Goal: Transition your scheduling environment to recognize Flex features rather than traditional, 10-period grid limits.

Aeries Path (Find this in your Aeries Window):

Scheduling Process → Configurations → Scheduling Setup

What we are doing together:

  1. Open the **Scheduling Setup** page in your database.
  2. Look under the **Scheduling Status** section.
  3. Select the option **Use Flex Scheduling for Next Year**.
  4. Ensure the checkbox for **Use Staff-Section Association instead of Teacher Number (TN)** is checked. This enables multi-teacher configurations.
  5. If you are importing a traditional schedule, locate and click the **Convert to Flex Scheduling** utility at the bottom of the page. This converts existing traditional sections into Flex format.
Beginner Mistake: Initializing the schedule without enabling the "Staff-Section Association" flag. If you rely on traditional Teacher Numbers (TCH), Aeries will prevent you from assigning co-teachers, push-in RSP specialists, or counselors to active sections.

Step 2 — Create Custom Flex Periods (FTF Table)

Flex Milestone 2 • Defining Time Blocks

Goal: Construct your periods as independent records with explicit start times, end times, and period codes.

Aeries Path (Find this in your Aeries Window):

Attendance Accounting → Configurations → Flex Periods

What we are doing together:

  1. Click **Add New Record** to create a Flex Period.
  2. Enter a **Short Title** (limited to 6 characters, such as `P1`, `ADVIS`, or `WIN`). This is what prints on student schedule documents.
  3. Enter the **Start Time** and **End Time** for the period block.
  4. Select the **Type** for the period:
    • Standard: Standard academic classes. Aeries will actively search for and flag student or teacher conflicts.
    • C - Non-Conflict: Used for pull-outs, advisories, or unstructured blocks. Aeries will NOT check for student scheduling overlaps in this block.
The Pull-Out Rule: By designating support periods (like RSP, speech, or independent study) as **Type C (Non-Conflict)**, teachers can keep accurate attendance without forcing counselors to balance overlapping course request conflicts.

Step 3 — Build and Assign Class Calendars (CCL)

Flex Milestone 3 • Calendar Mapping

Goal: Specify which dates throughout the year a section is active. Essential for building A/B blocks or multi-term elective wheels.

Aeries Path (Find this in your Aeries Window):

Scheduling Process → Scheduling Master Schedule → Section Details

What we are doing together:

  1. Navigate to **Attendance Accounting → Configurations → Class Calendars**.
  2. Create a new calendar profile (e.g., `A-DAY` or `B-DAY`) and select the matching instructional days from the main year calendar.
  3. Navigate to your section details page on the Scheduling Master Schedule (SMS).
  4. Map the Section's Class Calendar (SMS.CSQ) to your custom calendar ID.
Validation Step: If a student has an A-Day class mapped to a calendar and a B-Day class mapped to another, Aeries will schedule both into the same period block without creating a conflict reject code.

Step 4 — Implement WIN (What I Need) Rotation Blocks

Flex Milestone 4 • Flex Interventions

Goal: Structure mid-day support blocks where students are placed dynamically into intervention or enrichment groups weekly.

What we are doing together:

  1. Create a unified course code in your catalog: e.g., `Course 9901 - WIN Support Block`. Set it as **Non-Credit / No Grade** so it does not calculate into GPAs.
  2. Build corresponding sections in your Scheduling Master Schedule (SMS) during your designated WIN period.
  3. Roster students into a permanent homeroom/WIN teacher section in Aeries for official state attendance reporting.
  4. For weekly rosters, use Aeries **Supplemental Groups** or shared district tracking lists to manage student rotation schedules. This maintains clean attendance audits.

Step 5 — Run Flex Validation Reports & Queries

Flex Milestone 5 • Testing Configurations

Goal: Execute database validations to verify that all flex sections have valid times, teachers, calendars, and structural setups.

Aeries Path (Find this in your Aeries Window):

Scheduling Process → Reports → Prescheduling Edit Listing

Essential Flex Verification Queries:

Run these commands inside your Aeries Query window to catch missing calendar IDs or period sequence mismatches before running the scheduler:

Identify Sections Missing Class Calendars: 
LIST SMS SSM STF STF.FN STF.LN SMS.SE SMS.FSQ SMS.CSQ SMS.ES BY STF.LN STF.FN IF ( SSM.PR = 1 AND SMS.CSQ < 1 )
List Sections with Exclusions Turn On: 
LIST SMS SSM STF STF.FN STF.LN SMS.SE SMS.ES BY STF.LN STF.FN IF SMS.ES = 1
