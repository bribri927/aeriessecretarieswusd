Playbook 1 • Data Adjustments & Auditing

How to Correct Attendance Step-by-Step

Attendance corrections must follow standard, legal pathways. Every absence change can affect district funding (ADA) and must be backed up by physical documentation (phone logs, doctor notes, or signed slips).

Aeries Navigation & Execution Path:

  1. Look up the student: Type the student ID or name inside your Aeries search bar.
    Left Sidebar → Attendance → Attendance Detail
  2. Verify parent excusal timelines: California Ed Code allows exactly 3 school days after an absence to submit validation notes. If a note is received late, the unexcused absence remains.
  3. Execute the Correction: Select the active date from the attendance calendar.
    Attendance Detail Page → Click [Update] button

    Change the unexcused absence code (such as A) to the correct verified code (e.g., E for excused illness). If the correction applies only to single periods (at secondary levels), click individual period fields.

  4. Log notes in the verification window: Double-click the date field to open the comments sub-box. Write who authorized the correction and save.
    Audit Comment Format: "Rec'd doctor note on 10/12/2026. Excused by J. Doe (Clerk)."
🚨 Legal Auditing Warning:

Never leave an attendance correction notes field empty. In a state attendance audit, any undocumented code changes from 'Unexcused' to 'Excused' are automatically flagged, exposing the school to strict funding penalties.

Playbook 2 • Legal Compliance & Interventions

The Truancy and SARB Pipeline

Under CA Education Code Section 48260, any student absent from school without a valid excuse for 3 full days in a single school year (or tardy/absent for more than 30 minutes on three occasions) is legally classified as a **truant**.

1. Triggering Truancy Letter 1 (3 Absences)

Run Letter 1 sweeps weekly to notify families of initial unexcused absence milestones.

Aeries Path: Attendance Accounting → Reports → Attendance Letters
  1. Select **Letter 1** from the system report. Set parameters to query students with **3 or more** unexcused absences.
  2. Print the report. Save a PDF copy to the student’s digital cumulative records in Aeries.
  3. Mail the physical letter home to the parent/guardian.

2. Running Letter 2 & Parent Conferences (6 Absences)

Triggered after 6 unexcused absences. This step requires setting up an active intervention meeting.

  1. Query **Letter 2** parameters. This prints an official request for an in-person attendance contract meeting.
  2. Set up a conference with the parent, counselor, and vice principal.
  3. Log the signed attendance intervention contract directly under Aeries Student Programs.

3. SARB Escales (9+ Absences)

When a student breaches 9+ unexcused absences and violates their site contract, escalate the case to the district.

Left Sidebar → Student Data → Behavior → Discipline (DIS) or Student Programs

Compile the legal attendance audits, previous letters, contract meeting notes, and mail verification records. Route the full packet to the district School Attendance Review Board (SARB) coordinator.

Playbook 3 • Specialized Compliance & Exits

Independent Study Tracking & No-Show Cleanup

Short-Term Independent Study (IS) Compliance

Short-term Independent Study (between 3 and 14 consecutive school days) allows students to study from home without losing attendance funding. Strict tracking is required:

  1. Verify a **signed Master Agreement contract** is on file *before* the student departs.
  2. In Aeries, flag the scheduled days as **Pending Independent Study** using a placeholder code.
  3. Once academic assignments are returned and evaluated by teachers, obtain the **work evaluation form** detailing verified academic time.
  4. Change the placeholder codes on the Attendance Detail screen to **I** (Independent Study - Excused) based on the evaluated percentage of work completed.
Attendance Detail → Click [Update] → Use Code I for verified hours

No-Show Student Cleanup Protocols

On the first day of instruction, you must audit classroom rosters to identify students who did not attend. Keeping "no-show" students marked as active generates severe state reporting errors and throws off school attendance statistics.

  1. Run a **Missing Attendance Report** to verify which sections are unaccounted for.
  2. Identify students marked absent across *every* period block on day 1.
  3. Verify with the front office if parent check-in records or enrollment withdrawals are pending.
  4. If a student does not attend by the end of day 1 (or within your district's designated window), process a **No-Show Exit**. Withdraw the student using the day prior to the start of the school year as their exit date, and assign the appropriate "No Show" exit reason code.

⚠️ Chronic Absenteeism Tracker

California defines **Chronic Absenteeism** as missing **10% or more** of school days (typically 18+ days across a standard school year).

Weekly Audit Sweeps:

Run ADA reports weekly to identify students whose attendance rate has dropped below **90%**. Route these students directly to counselor coordination teams for Tier-2 attendance interventions.
