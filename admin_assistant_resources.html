Playbook 1 • Behavioral Compliance

Discipline Entry & California Ed Code Tracking

Accurate behavior tracking is a critical legal and state reporting mandate under CALPADS. Site admin assistants must log behavioral incidents in the Discipline (`DIS`) and Assertive Discipline (`ADS`) tables immediately after administrative actions are finalized.

Detailed Discipline Log Setup (DIS Table):

  1. Search for the student ID. Navigate to the Discipline module.
    Aeries Sidebar → Student Data → Behavior → Discipline
  2. Click **Add New Record** at the bottom of the form.
  3. Input the exact **Incident Date** and **Time**.
  4. Select the correct California Education Code **Infraction Code** from the dropdown menu (e.g., *48900(a)(1) - Mutual Combat* or *48900(k) - Disruption*).
  5. Action & Suspension Details: Log the consequence (e.g., Out-of-School Suspension, In-School Suspension, Friday School) along with the start and end dates.
  6. State Reporting Fields: Verify that the state-mandated suspension day count matches the physical administrative letters sent to parents.
  7. In the **Comments/Details** box, record objective observations from the administrator's investigation. Avoid hearsay or subjective language.
    Objective Entry Format: "Student engaged in mutual combat on blacktop. Parents notified via telephone on 10/12/26. Suspension letter mailed home."
  8. Click **Save** to lock the record. Scan and upload the signed suspension packet directly to the student’s Documents tab.
🚨 Legal Notification Compliance Warning:

Under California Education Code, a parent/guardian must be formally notified of suspension actions in writing. Ensure the 'Notification Date' and 'Mailed Date' fields are filled out in the `DIS` record to prove timeline compliance during localized state behavior audits.

Playbook 2 • Administrative Logistics

SST, IEP & Parent Meeting Data Prep

Site admin assistants act as information dispatchers during parent-teacher conferences, Student Success Team (SST) meetings, and IEP reviews. Pulling student background reports cleanly prevents meeting delays.

The Standard Meeting Prep Packet Sequence:

  1. Generate the student profile worksheet: Look up the student to load their Demographic profile card.
    Aeries Navigation: Student Data → Demographics

    Print the Demographic details page directly to have physical contact and emergency contact lists ready.

  2. Export Academic Transcripts (HIS Table): Navigate to Course History to evaluate historical performance and current credits.
    Aeries Navigation: Student Data → Course History (HIS)

    Click **Print Transcript**, leaving unofficial/draft status checked for counselors and parents.

  3. Extract Active Attendance History (ATT Table): Open the student's Attendance details to analyze chronic absences or high tardy percentages.
    Aeries Navigation: Attendance → Attendance Detail

    Print the active year attendance summary calendar to locate scheduling or truancy patterns before meeting times.

Playbook 3 • Data Filtering

Creating Custom Student Lists & Filter Rosters

When site leaders request specific student rosters (e.g., *Active 10th graders assigned to Counselor B with a GPA below 2.0*), assistants can use Aeries student filters to construct targeted lists rapidly without using complex SQL databases.

Step-by-Step Custom Filtering Sequence:

  1. Navigate to the Aeries student search bar.
  2. Trigger Search Filters: Click the small filter toggle icon located next to the search input.
  3. Select search attributes:
    • Set **Grade (GR)** to the target class level (e.g., *10*).
    • Set **Counselor (CNS)** to the target supervisor code.
    • Set **Status Code (TG)** to **Active (A)** to exclude withdrawn students.
  4. Click **Search**. Aeries will filter your active view to display only matching records.
  5. Exporting Your filtered list: Click the **Aeries Analytics / Export to Excel** button in the lower results card. This downloads a cleanly formatted XLS file ready for site leadership review.
Aeries Header Search → Toggle Search Filters → Select Attributes → Export Results

Playbook 4 • Administrative Communication

Generating Parent Mail Merges & Address Labels

How to Export Clean Mailing Lists for Word/Google Merges

Site-wide mailings (such as principal orientation flyers or report card mailers) require extracting clean parent mailing records without duplicate address rows:

  1. Open the Query utility. Run your target parent address extract query.
    Aeries Path: Header Search → Reports → Query
  2. Copy the WUSD parent address query:
    LIST STU CON STU.ID STU.NM CON.NM CON.AD CON.CY CON.ST CON.ZP IF CON.AD > "" AND CON.OR = 1

    This isolates Primary parent addresses (Contact Order = 1) to prevent sending duplicate letters to the same family home.

  3. Select **Run Query**. Click the **Export** button. Save the output as a `.csv` file.
  4. Open Microsoft Word or Google Docs. Select **Mailings → Start Mail Merge**.
  5. Choose **Select Recipients → Use an Existing List**, then select your downloaded Aeries CSV file.
  6. Insert Merge Fields (e.g., Parent Name, Address, City, State, Zip) onto your document, and select **Finish & Merge** to generate print-ready letters.
