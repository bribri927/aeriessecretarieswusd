📝 2-Min Sprint

The 2-Minute Attendance Dash

The legal roll-call checklist. Present students remain completely blank. Absent students are marked as Absent (A), and late arrivals are updated immediately to Tardy (T).

Aeries Sidebar → Attendance → Take Attendance
📘 3-Min Initializer

The 3-Minute Gradebook Setup

Setting up weighted categories. Check the "Do Weighted Grading" box under configurations, enter categories (Homework, Tests), and confirm weights total exactly 100%.

Manage Gradebook → Categories → Add Category
📊 5-Min Rollup

The 5-Minute Report Card Rollup

Migrating gradebook totals. Import grades directly into report card tables (`GRD`), enter citizenship codes (O, S, N, U), select comment codes, and sign the verification printout.

Grades → Grade Reporting → Initialize Grade Reporting

Annual Refresher Calendar & Milestones

Track key operational milestones by season to maintain compliant database records:

August / September

Beginning-Of-Year Setups

  • Create active gradebook cards and link adjacent sections.
  • Set up syllabus categories and confirm weights total 100%.
  • Audit opening week attendance and run the Student Import utility to pull new roster enrollments.
December / January

Semester / Quarter Rotations

  • Run missing assignment sweeps (`MI` code check) before grading locks.
  • Import term averages to report cards and double-click to add comment codes.
  • Re-authorize G-Suite/Canvas secure tokens to prevent grade passback failures.
May / June

End-Of-Year Grade Archival

  • Confirm all outstanding assignments are scored or marked `EX` / `MI`.
  • Generate clean progress reports, print parent summaries, and collect signatures.
  • Print, sign, and deliver the final Term Grade Verification Sheet to the site registrar.
